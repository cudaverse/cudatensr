# Extract embedding coordinates

Extract embedding coordinates

## Usage

``` r
embedding_coordinates(x)
```

## Arguments

- x:

  A `cuda_embedding`.

## Value

Numeric coordinate matrix.

## Examples

``` r
fit <- cuda_diffusion_map(
  matrix(rnorm(60), 20, 3),
  n_components = 2,
  device = "cpu"
)
embedding_coordinates(fit)
```
